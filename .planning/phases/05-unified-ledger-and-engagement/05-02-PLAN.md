## 1. Context & Objectives

In OmniPost V1, content generation used static heuristics and manual voice profiling via `scripts/voice_profile.py`. In V2, OmniPost publishes across 4 disparate networks with distinct algorithmic distribution curves.

To transform OmniPost into a truly autonomous, self-improving publishing engine:
1. We must aggregate real post engagement metrics (likes, reposts, comments, views) across enabled channels without incurring paid API costs.
2. For Bluesky, ATProto offers free, public HTTP endpoints (`app.bsky.feed.getPostThread`) with zero rate limits or auth requirements.
3. For X, LinkedIn, and Threads, metrics can be scraped via our existing stealth CDP browser sessions.
4. We must close the loop by calculating engagement scores, identifying winning hooks and optimal post structures, and updating `references/voice-profile.local.md` so that future research and repurposing (`scripts/repurpose.py`) automatically adopt top-performing formats.

```json
{
  "platforms": {
    "bluesky": {

      "url": "https://bsky.app/profile/user.bsky.social/post/3kq...",

        "replies": 5,
        "updated_at": "2026-10-05T12:00:00Z"
      }
    },
    "x": {
      "status": "published",
      "url": "https://x.com/Lordporus/status/...",
      "metrics": {
        "likes": 128,
        "reposts": 19,
        "replies": 14,
        "views": 4500,
        "updated_at": "2026-10-05T12:00:00Z"
      }
    }
  }

```

### Engagement Score Formula:
$$\text{Score} = \text{Likes} + (2 \times \text{Reposts}) + (3 \times \text{Replies}) + \left(\frac{\text{Views}}{100}\right)$$

Posts in the top 20th percentile are categorized as **High-Leverage Posts**.

## 4. Implementation Steps

### Step 1: Create `scripts/analytics.py`
* **Bluesky Collector:** Calls `https://public.api.bsky.app/xrpc/app.bsky.feed.getPostThread?uri={at_uri}` using standard `urllib.request`. Extracts `likeCount`, `repostCount`, `replyCount`. Zero API cost, zero tokens needed.
* **CDP Collector (X, LinkedIn, Threads):** Reuses `scripts.browser.ensure_chrome()` and stealth DOM evaluation to read like/repost/comment counts from recent profile posts.
* **CLI Interface:**
  - `python scripts/analytics.py collect [--days 7]`: Iterates over recent posts in `state.json` and fetches updated metrics.
  - `python scripts/analytics.py report`: Prints a formatted performance leaderboard sorted by engagement score.

### Step 2: Create `scripts/feedback.py`
* **Score & Rank:** Computes engagement scores for all measured posts.
* **Pattern Extraction:**
  - Hook categorization (Question, Contrarian, Numbered List, Anecdote).
  - Average characters vs engagement correlation.
  - Best-performing visual formats (Infocard vs PDF Carousel vs Plain text).
* **Feedback Write-Back:** Generates or updates the `## Learned Algorithmic Preferences` section in `references/voice-profile.local.md`, providing dynamic feedback to `scripts/repurpose.py` and `scripts/research.py`.
