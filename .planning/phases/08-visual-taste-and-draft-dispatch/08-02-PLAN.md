## 1. Context & Objectives

Currently, `scripts/generate.py` and `scripts/repurpose.py` produce low-quality fallback slides:
1. They generate slides with empty `bullets` lists, which causes the carousel renderer to emit empty card boxes.
2. They repeat the same headline word-for-word on Slide 1, 2, and 3.
3. They use cheap meta-labels (`01. Overview`, `02. Technical Context`, `03. Key Takeaway`, `04. Summary`), strictly violating `/gpt-taste` Section 7 and `/taste-design` Section 9.
4. They inject irrelevant hardcoded blueprints into Slide 1 and raw URLs into Slide 4.

**Goal:**
1. Upgrade `extract_key_takeaways()` and topic synthesis in `scripts/generate.py` to always generate at least 3 distinct, high-impact bullet points.
2. Replace hardcoded numbered meta-labels with semantic, topic-derived slide titles (e.g. *"The Core Architecture"*, *"Incident Post-Mortem"*, *"Production Impact Checklist"*).
3. Ensure Slide 1, 2, and 3 have strictly unique content without echoing the headline.
4. Clean up takeaway URLs in Slide 4 into a clean domain badge (e.g., `github.com • Verified Reference`).

## 2. Technical Specification

### 2.1 Bullet Point & Takeaway Extraction Guarantee
- Modify `extract_key_takeaways(text)` in `scripts/generate.py` to ensure robust multi-sentence extraction.
- Guarantee that every slide definition in the generated `carousel` dict includes:
  - `header`: Semantic title (banning "01. Overview", "02. Technical Context")
  - `body`: Informative narrative explanation (different from the headline)
  - `bullets`: List of 2–3 specific actionable technical points

### 2.2 Carousel Schema Contract in `scripts/generate.py`
```python
carousel = {
    "title": title[:70],
    "slides": [
        {
            "header": title[:60],
            "body": f"Architectural breakdown of {title} and its production impact.",
            "tag": category,
            "bullets": points[:2] if len(points) >= 2 else ["High-availability design pattern", "Decoupled state management"]
        },
        {
            "header": "Core Architectural Friction",
            "body": body[:200],
            "tag": "BOTTLENECK",
            "bullets": [points[0]] if points else ["Unverified state cascades across services"]
        },
        {
            "header": "Implementation Pattern",
            "body": points[1] if len(points) > 1 else "State machine verification pattern",
            "tag": "IMPLEMENTATION",
            "bullets": points[1:3] if len(points) > 2 else ["Deterministic execution beats flaky retry loops"]
        },
        {
            "header": "Production Verification Checklist",
            "body": f"Key takeaway: {takeaway}",
            "tag": "CHECKLIST",
            "bullets": [
                "Atomic state persistence",
                "Isolated failure recovery",
                "Verified credential boundaries"
            ]
        }
    ]
}
```

### 2.3 Verification Criteria
1. Running `python -c "from scripts.generate import generate_topic_from_items; t = generate_topic_from_items('tech_insight', [{'title': 'Test Item', 'summary': 'Line 1. Line 2. Line 3.'}]); print([len(s.get('bullets', [])) for s in t['carousel']['slides']])"` returns non-zero counts for every slide.
2. Zero occurrences of strings matching `r"^0\d\.\s*(Overview|Technical Context|Key Takeaway|Summary)"`.
