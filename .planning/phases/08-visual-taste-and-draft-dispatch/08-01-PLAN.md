## 1. Context & Objectives

When users execute `python scripts/publish_now.py --draft drafts/YYYY-MM-DD.json`, the command currently crashes with:
`[ERROR] Post text or valid --draft must be provided.`

This occurs because `scripts/pipeline.py` outputs daily schedule files structured with a top-level `"slots": [...]` array, whereas `scripts/publish_now.py` expects root-level platform keys (`"platforms"` or `"x"`).

**Goal:**
1. Upgrade `scripts/publish_now.py` to intelligently unwrap daily schedule files containing `"slots"`.
2. Add a `--slot` argument (e.g. `--slot 13:00`) allowing the operator to publish a specific slot on demand.
3. If `--slot` is not specified, auto-select the first unposted slot (`s.get("posted") == False`), or fallback to `slots[0]`.
4. Ensure full backward compatibility for flat standalone draft JSONs.

---

## 2. Technical Specification

### 2.1 Argument Parsing in `scripts/publish_now.py`
Add argument:
```python
parser.add_argument("--slot", help="Specific time slot to publish from daily draft (e.g. 13:00)")
```

### 2.2 Slot Extraction Logic
Inside `scripts/publish_now.py`:
```python
if "slots" in draft_data and isinstance(draft_data["slots"], list) and len(draft_data["slots"]) > 0:
    selected = None
    if args.slot:
        selected = next((s for s in draft_data["slots"] if s.get("slot") == args.slot.strip()), None)
        if not selected:
            print(f"[ERROR] Slot '{args.slot}' not found in draft file. Available: {[s.get('slot') for s in draft_data['slots']]}", flush=True)
            return 1
    else:
        # Default to first unposted slot, or slots[0]
        selected = next((s for s in draft_data["slots"] if not s.get("posted", False)), draft_data["slots"][0])
    
    # Promote selected slot platforms and text to draft_data context
    draft_data = selected
```

### 2.3 Verification Criteria
1. Executing `python scripts/publish_now.py --draft drafts/2026-10-18.json --dry-run` succeeds and outputs preview for all active platforms.
2. Executing with `--slot 16:00 --dry-run` accurately picks the 16:00 slot.
