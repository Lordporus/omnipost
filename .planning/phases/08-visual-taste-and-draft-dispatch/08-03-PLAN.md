## 1. Context & Objectives

Visual evaluation of `scratch/carousels/preview.html` and `architecture_carousel.pdf` reveals significant visual anti-patterns:
- **Font:** Uses banned generic `Inter` (`taste-design` & `gpt-taste` ban Inter for creative/editorial content).
- **Empty Voids:** Empty card containers `<div class="card-panel">` render when bullets are missing.
- **Palette Clutter:** Competing Emerald, Amber, Cyan accents and multiple heavy gradients violate the "max 1 accent, <80% saturation" rule.
- **Filler Elements:** Banned `"Swipe ➔"` text in footers.
- **Hero Title Hierarchy:** Slide 1 displays a small 56px font in an unbalanced container, with confusing badge labels.

**Goal:**
1. Upgrade typography stack in `render/template.html` to Google Fonts **Geist** (`Geist:wght@400;600;700;800;900`) and **Geist Mono**.
2. Calibrate color palette to an authoritative Obsidian / Deep Slate base with a single high-contrast precision accent (`#00E599` or `#00D2FE`).
3. Enforce **Zero Empty Void** in `render/carousel.py`: only render `.card-panel` if valid bullets, code, or narrative content exists.
4. Replace `"Swipe ➔"` with sleek slide pagination indicators (`● ○ ○ ○`).
5. Ensure 1080x1080 vector PDF output rendered via CDP Page.printToPDF looks like an Awwwards-caliber technical publication.

## 2. Technical Specification

### 2.1 Typography & Google Fonts Upgrade (`render/template.html`)
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Geist:wght@400;500;600;700;800;900&family=Geist+Mono:wght@500;600;700&display=swap" rel="stylesheet">
```

CSS variables:
```css
:root {
  --bg-canvas: #080A0F;

  --bg-card-elevated: #151A27;
  --border-card: rgba(255, 255, 255, 0.08);

  --text-primary: #FFFFFF;
  --text-secondary: #94A3B8;
  --text-muted: #64748B;

  --accent-primary: #00E599; /* Precision Electric Emerald */

}
```
