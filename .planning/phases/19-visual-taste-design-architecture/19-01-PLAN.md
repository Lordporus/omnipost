  <name>Task 1: Semantic Design Contract (DESIGN.md)</name>
  <files>render/DESIGN.md</files>
  <read_first>humanized_quality_and_taste_plan.md</read_first>
  <action>
1. Create `render/DESIGN.md` establishing the semantic design system for all visual generation:
   - **Atmosphere:** High-agency, tactile engineering studio. Minimal, sharp, clinical.
   - **Color System:**
     - Base Canvas: Deep Zinc Slate (`#090D16` / `#0D1117`). Pure black (`#000000`) is strictly forbidden.
     - Elevated Panel Surface: `#121824`.
     - Border Tokens: Subtle line `rgba(255, 255, 255, 0.08)` and active accent line `rgba(0, 229, 153, 0.25)`.
     - Accent: Maximum 1 singular accent with saturation < 80% (`#00E599` emerald or `#38BDF8` cyan).
     - Text Primary: `#F1F5F9` (Slate-100); Text Secondary: `#94A3B8` (Slate-400); Text Muted: `#64748B` (Slate-500).
   - **Typography Rules:**
     - Display: Vendored `Geist` font family with tight tracking (`-0.035em`) for headlines (max 3 lines).
     - Technical/Artifacts: Vendored `Geist Mono` for architecture nodes, terminal code, metrics, and badges.
   - **Layout Hierarchy & Widgets:**
     - Header (15%): Brand monogram/handle, category badge (`[SYSTEMS DESIGN]`), pagination (`01 / 03`).
     - Hero (70%): 2-line punchy claim followed by an interactive widget:
       - *Architecture Flow Panel*: Monospace component boxes with directional arrows (`[Client] -> [Gateway] -> [DB]`).
       - *Terminal Code Panel*: Dark editor window with tab header, line numbers, and syntax highlighting.
       - *Problem Anatomy*: 2-column contrast (`Naive Approach` vs. `Production Fix`).
       - *Tactile Checklist*: 3 crisp bullet points with monospace step indicators (`01`, `02`, `03`).
     - Footer (15%): Real source domain, timestamp, and minimal operator stamp.
   - **Strict Anti-Patterns:**
     - NO multi-color radial gradient washes.
     - NO neon drop-shadows (`box-shadow: 0 0 18px var(--emerald)`).
     - NO generic AI boilerplate labels (`THE CONTEXT`, `SYSTEM // 2026`).
     - NO raw unformatted multi-line abstract dumps.
  </action>
