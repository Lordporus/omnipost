## 1. Context & Objectives

Two major production lessons from TweetyTweets are:
1. **Zero Idle-Cost Scheduling**: Running an LLM agent on a cron schedule every 10 minutes becomes expensive if the agent runs unconditionally. TweetyTweets uses a lightweight gate script that returns an exact, byte-identical `IDLE` when nothing is due, suppressing the agent and costing \$0. OmniPost has `daemon.py` and `cron_gate.py`, but needs an explicit `scripts/gate.py` that matches this exact pattern and document the zero-cost architecture.
2. **Authentic Voice & Ritualized Onboarding**: Generic AI voices sound like bots. Authentic voice profiling requires a structured ritual: analyzing 5-20 top-performing posts (100k+ impressions), extracting syntactic rhythms, and enforcing a strict "do-not" list (banned corporate buzzwords, emojis, rhetorical tropes). Furthermore, before automation is ever enabled, onboarding must execute a live character limit measurement and a supervised first-post ceremony.

**Goal:** Implement `scripts/gate.py` with byte-identical `IDLE` output, upgrade `scripts/voice_profile.py` with an interactive measurement ritual and mandatory "do-not" lists, and enhance `scripts/wizard.py` / `setup.py` with character limit measurement and supervised first-post confirmation.

## 2. Technical Architecture & Contracts

### A. The Zero-Cost Idle Gate (`scripts/gate.py`)
- Callable by cron, systemd timer, or task scheduler.
- Executes purely in Python stdlib with 0 external network/LLM dependencies.
- Exit code and stdout contract:
  - If nothing is due: prints exact byte-identical string `IDLE\n` and exits `0`. Cron / runner filters `IDLE` and suppresses the downstream agent. Total cost: **\$0.00**.
  - If a slot is due: prints compact JSON string `{"slot": "...", "draft": {...}, "tick": 123}\n` and exits `0`. Cron invokes the agent with this input.
  - If error: prints error to `stderr` and exits `1`.
- Flag `--wake`: prints full instruction block formatted for direct agent consumption.

### B. Voice Authenticity Measurement Ritual (`scripts/voice_profile.py`)
- Ritual workflow:
  1. Prompts or reads 5 to 20 proven top-performing posts (100k+ impressions or user's best work).
  2. Measures quantitative metrics: average sentence length, paragraph break density, hook structure, question-to-statement ratio.
  3. Formulates a mandatory **DO-NOT List**:
     - Banned phrases: "In today's fast-paced world", "Game changer", "Dive into", "Excited to announce".
     - Banned punctuation: No exclamation marks in technical posts, no hashtags in body.
     - Banned styles: No engagement bait questions ("Agree?"), no moralizing wrap-ups.
  4. Saves profile to `references/voice-profile.local.md`.
  5. **Hard Rule:** If `references/voice-profile.local.md` is missing or the "DO-NOT" list is empty, content generation aborts with a loud error instead of guessing or falling back to generic AI tone.

### C. Onboarding Ceremony (`scripts/wizard.py` & `setup.py`)
- Step 3.5: **Measure Character Limit**
  - Runs `python scripts/post.py measure --save` for enabled platforms.
  - Verifies exact live character limit from composer DOM or API.
- Step 6.5: **One Supervised Post Ritual**
  - Interactive test post: prompts user for test copy or generates sample post.
  - Renders visual preview / captures screenshot into `shots/preview.png`.
  - Prompts operator: `Confirm live post to [handle]? [y/N]`.
  - Submits live post and executes read-back verification.
  - Only unlocks automated daemon / cron setup after the supervised post succeeds.
