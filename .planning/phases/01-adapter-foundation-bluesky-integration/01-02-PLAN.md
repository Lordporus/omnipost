<task type="auto">
  <name>Task 2: Implement BlueskyAdapter XRPC Operations</name>
  <files>adapters/bluesky.py</files>
  <read_first>adapters/base.py, docs/EXPANSION_BLUEPRINT_MULTI_PLATFORM.md</read_first>
  <action>
    Implement `BlueskyAdapter(PlatformAdapter)`:
    1. Configuration & auth loading:
       - Identifier (`handle.bsky.social`) from `config.json` or argument.
       - App Password from `BSKY_APP_PASSWORD` environment variable or `config.json`.
    2. `check_session()`:
       - Calls `com.atproto.server.createSession` via `urllib.request`.
       - Returns `{"logged_in": True, "handle": ..., "did": ...}` on success.
    3. `upload_blob(path: Path) -> dict`:
       - Reads file bytes, inspects MIME type (image/png or image/jpeg).
       - Calls `com.atproto.repo.uploadBlob` with binary payload.
       - Returns blob reference dict with CID and size.
    4. `publish(payload: PublishPayload) -> PublishResult`:
       - Extracts facets using `extract_facets(payload.text)`.
       - Uploads media if `payload.media_paths` provided.
       - Calls `com.atproto.repo.createRecord` with `collection: "app.bsky.feed.post"`.
       - Returns `PublishResult(platform="bluesky", success=True, post_id=rkey, url=...)`.
    5. `verify(post_id, text_snippet)`:
       - Queries public endpoint `app.bsky.feed.getAuthorFeed` or `com.atproto.repo.getRecord` to confirm post status live.
  </action>
  <verify>python -c "from adapters.bluesky import BlueskyAdapter; b = BlueskyAdapter(); print(b.platform_name, b.capabilities.max_characters)"</verify>
  <acceptance_criteria>
    - BlueskyAdapter conforms to PlatformAdapter
    - All network calls use stdlib urllib with error handling
    - Supports both text-only and image-attached posts
  </acceptance_criteria>
  <done>BlueskyAdapter implemented</done>
</task>
