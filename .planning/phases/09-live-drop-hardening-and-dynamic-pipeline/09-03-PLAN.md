## 1. Context & Objectives

Currently, `adapters/linkedin.py` uses an 8-step sequence of toolbar button queries, overflow menu clicking, and detour prompts to attach documents. On standard viewports, LinkedIn frequently hides the document icon behind secondary menus or updates aria labels, causing the script to return `Failed to attach PDF carousel document`.

**The Solution:**  
LinkedIn's web post composer natively supports dragging and dropping files. When a `.pdf` file is dragged and dropped onto the composer surface (`div.share-box` / `div[role="dialog"]`), LinkedIn immediately accepts the document and switches directly to the Document Title prompt in under 3 seconds, bypassing:
- Toolbar scanning
- Overflow menu clicking
- OS file picker dialogs
- Multiple modal transition delays

**Goals:**
1. Implement native CDP drag-and-drop file synthesis in `adapters/linkedin.py` via `Input.dispatchDragEvent` and `DataTransfer` file drop injection.
2. Fast-forward upload time to < 5 seconds with 1 single deterministic interaction.
3. Automatically fill document title, click "Done", inject LinkedIn text, and submit.
4. Resilient fallback: if a requested PDF attachment is rejected, capture `shots/linkedin_fail.png`, return a typed `MediaContractError` failure, and stop publishing. Text-only publishing is allowed only when the payload explicitly requests no media.

## 2. Technical Specification

### 2.1 CDP Drag-and-Drop Dispatch in `adapters/linkedin.py`
Add `_drag_and_drop_pdf(page, pdf_path)`:
```python
async def _drag_and_drop_pdf(self, page: Session, pdf_path: Path) -> bool:
    """Simulates native CDP drag-and-drop of PDF file onto LinkedIn post composer."""
    if not pdf_path.exists():
        return False
    
    # 1. Get coordinates of composer dropzone
    dropzone_js = """
    (() => {
        const el = document.querySelector('div.share-box-feed-entry__wrapper')
            || document.querySelector('div[role="dialog"]')
            || document.querySelector('div.ql-editor')
            || document.querySelector('.share-box');
        if (!el) return null;
        const r = el.getBoundingClientRect();
        return {x: Math.round(r.left + r.width / 2), y: Math.round(r.top + r.height / 2)};
    })()
    """
    pos = await page.eval(dropzone_js)
    if not pos:
        return False

    # 2. Attach file via DOM.setFileInputFiles on any composer input or dispatch DataTransfer drop
    # Settle and verify LinkedIn switches to Document Title screen
    # 3. Poll up to 5s for Document Title input
    return True
```

### 2.2 Title Injection & Final Post
1. Inject `clean_title` via `Input.insertText` on `input[id*="document-title"]`.
2. Click blue "Done" button (`button.share-box-footer__primary-btn` or button containing "Done").
3. Settle back in main composer, type text, and submit.
