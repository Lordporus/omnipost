## 1. Context & Objectives

In the latest live run, Threads failed with `Could not focus Threads post composer editor`. Meta Threads uses Meta's **Lexical rich-text framework** inside React 18 concurrent mode. Calling standard DOM `.focus()` on a contenteditable `div` does not dispatch React's SyntheticEvent `onFocus` or `onBeforeInput`, leaving the editor unhydrated and causing text insertion to fail or time out.

**Goals:**
1. Upgrade Threads composer trigger and editor focus to dispatch authentic mouse events (`mousedown`, `mouseup`, `click`) at the exact bounding box center of the Lexical editor.
2. Dispatch `beforeinput` and `focus` events with bubbles: true.
3. Verify active focus via `document.activeElement` before calling `Input.insertText`.
4. Capture `shots/threads_fail.png` on any focus failure for immediate visual proof.

## 2. Technical Specification

### 2.1 Authentic Lexical Coordinate Focusing in `adapters/threads.py`
In `FOCUS_EDITOR_JS`:
```javascript
(() => {
  const ed = document.querySelector('div[contenteditable="true"][role="textbox"]')
    || document.querySelector('div[data-lexical-editor="true"]')
    || document.querySelector('div.notranslate[contenteditable="true"]')
    || document.querySelector('div[role="combobox"][contenteditable="true"]')
    || document.querySelector('div[contenteditable="true"]')
    || document.querySelector('div[role="textbox"]');
  if (!ed) return JSON.stringify({status: 'no_editor'});

  ed.scrollIntoView({block: 'center', inline: 'nearest'});
  const r = ed.getBoundingClientRect();
  const coords = {x: Math.round(r.left + r.width / 2), y: Math.round(r.top + r.height / 2)};

  ed.focus();
  try {
    ed.click();
    ed.dispatchEvent(new MouseEvent('mousedown', {bubbles: true, cancelable: true, clientX: coords.x, clientY: coords.y}));
    ed.dispatchEvent(new MouseEvent('mouseup', {bubbles: true, cancelable: true, clientX: coords.x, clientY: coords.y}));
    ed.dispatchEvent(new Event('focus', { bubbles: true }));
  } catch (e) {}

  return JSON.stringify({
    status: 'focused',
    coords: coords,
    is_active: document.activeElement === ed
  });
})()
```

### 2.2 CDP Mouse Input Dispatch
If `coords` are returned, also dispatch CDP `Input.dispatchMouseEvent` (`mousePressed`, `mouseReleased`) to ensure Chromium's native input pipeline marks the element as the active text target.
