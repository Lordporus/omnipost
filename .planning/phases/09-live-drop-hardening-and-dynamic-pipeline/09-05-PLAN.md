## 1. Context & Objectives

Currently, running `publish_now.py` repeatedly drops the exact same text and static PDF from `drafts/2026-10-18.json`, causing the deduplication guardrail to block posts and giving the user a stale experience.

**Goals:**
1. **Dynamic Daily Intelligence:** Integrate `scripts/curate.py` / `scripts/research.py` to scrape live trending discussions (Hacker News, RSS, Reddit) and compile today's fresh draft (`drafts/YYYY-MM-DD.json`) with 4 distinct technical topics across slots (`13:00`, `16:00`, `20:00`, `00:00`).
2. **Unique PDF Carousel Naming:** Update `render/carousel.py` to stop overwriting `architecture_carousel.pdf`. Output uniquely per slot: `scratch/carousels/carousel_<date>_<slot>.pdf`.
3. **Turnkey Live Drop Command:** Add `--fresh` flag to `scripts/publish_now.py`:
   `python scripts/publish_now.py --fresh`
   - Automatically pulls fresh research.
   - Generates today's multi-slot draft.
   - Compiles the unique dynamic PDF carousel for the active slot.
   - Publishes across all 4 platforms with zero duplicate content issues.

## 2. Technical Specification

### 2.1 Unique PDF Carousel Output Naming in `render/carousel.py`
```python
slot_tag = args.slot.replace(":", "") if args.slot else "default"
date_tag = args.date or datetime.now().strftime("%Y-%m-%d")
out_pdf = carousels_dir / f"carousel_{date_tag}_{slot_tag}.pdf"
```
Update draft metadata to reference this specific file path for LinkedIn document uploads.

### 2.2 Turnkey `--fresh` Pipeline in `scripts/publish_now.py`
Add flag:
```python
parser.add_argument("--fresh", action="store_true", help="Generate fresh research draft & unique carousel before publishing")
```
When `--fresh` is specified:
1. Calls `curate.curate_daily_plan()` to compile today's draft file.
2. Selects active slot based on current system time.
3. Compiles dynamic vector PDF for that slot.
4. Drops to all 4 platforms in one seamless pass.
