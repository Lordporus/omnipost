  <files>docs/DEPLOY_VERIFICATION.md, config.json</files>
  <read_first>docker-compose.yml, Dockerfile, GROWTH_AND_PIPELINE_FIX_PLAN.md</read_first>
  <action>
This task needs the deployment host and must not be simulated.

1. Record the source revision: `git rev-parse main`.
2. Rebuild and restart:
   ```powershell
   docker compose build omnipost
   docker compose up -d omnipost
   ```
3. Confirm the container is healthy: `docker compose ps` must show `healthy`, not `starting`.
4. Compare the four guardrail files against the host. Host hashes:
   ```powershell
   Get-FileHash scripts/validator.py, scripts/pipeline.py, scripts/publish_now.py, scripts/due.py -Algorithm SHA256 | Select-Object Hash, Path
   ```
   Container hashes:
   ```powershell
   docker exec omnipost-engine python -c "import hashlib,pathlib; [print(hashlib.sha256(pathlib.Path(p).read_bytes()).hexdigest(), p) for p in ('scripts/validator.py','scripts/pipeline.py','scripts/publish_now.py','scripts/due.py')]"
   ```
   Every pair must match. If any differs, the image is stale; do not continue.
5. Read-only behaviour checks inside the container:
   ```powershell
   docker exec omnipost-engine python -c "import inspect, scripts.validator as v; print('check_measured' in inspect.getsource(v))"
   docker exec omnipost-engine python -c "import inspect, scripts.pipeline as p; print('check_measured=False' in inspect.getsource(p))"
   docker exec omnipost-engine python -c "import inspect, scripts.publish_now as n; print('check_measured=False' in inspect.getsource(n))"
   docker exec omnipost-engine python scripts/due.py show --date (Get-Date -Format yyyy-MM-dd)
   ```
   The three imports must print `True`. `due.py show` must print the plan without error.
   **Do not run `docker exec ... python scripts/due.py check`**: it increments the tick counter and can retire overdue slots. `show` is read-only.
6. Write `docs/DEPLOY_VERIFICATION.md` with: date, source commit, image ID (`docker inspect --format '{{.Image}}' omnipost-engine`), the eight hashes, the three boolean results, and the `due.py show` outcome.
7. If the container reads `config.json` and the account ceiling is still unmeasured, run the measurement on the host before trusting any scheduled publish: `py -3.12 scripts/post.py measure --save`. Record the value in the doc; never set `max_chars_verified: true` by hand.
  </action>
