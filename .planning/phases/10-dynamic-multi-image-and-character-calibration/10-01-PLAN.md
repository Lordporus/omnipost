## 1. Context & Objectives

In the latest live drop, the post read:
`Mercury 3: Diffusion at scale. Mercury 3: Diffusion at scale`
`Key Engineering Takeaways: ▸ Mercury 3: Diffusion at scale...`

This happened because `scripts/generate.py` duplicated the title when the article summary was brief or empty, and hardcoded a 4-slide structure regardless of content depth.

**Goals:**
1. Eradicate title/body/bullet echoing in `scripts/generate.py`.
2. Synthesize deep technical context (analyzing architecture, bottlenecks, and solutions) whenever the scraped summary is under 80 characters.
3. Dynamically compute the optimal visual slide count ($N \in \{1, 2, 3\}$) based on takeaway depth rather than hardcoding 4 slides.
4. Guarantee all bullets are unique, non-trivial, and actionable.

## 2. Technical Specification

### 2.1 Dynamic Card Density Evaluation in `scripts/generate.py`
```python
def determine_card_count(topic_data: dict[str, Any]) -> int:
    """Calculates whether content warrants 1, 2, or 3 visual cards.
    
    - 1 Card: Concise insight or single takeaway (< 150 chars body, <= 2 points).
    - 2 Cards: Problem vs. Solution or comparative architectural tradeoff.
    - 3 Cards: Deep workflow (Hook/Context -> Architecture Engine -> Production Checklist).
    """
    points = [p for p in topic_data.get("points", []) if len(p.strip()) > 15]
    body = topic_data.get("body", "").strip()
    
    if len(points) >= 3 and len(body) > 200:
        return 3
    elif len(points) >= 2 or len(body) > 100:
        return 2
    return 1
```

### 2.2 Anti-Echo Deduplication Guard
```python
def sanitize_topic_content(headline: str, body: str, points: list[str]) -> tuple[str, str, list[str]]:
    """Guarantees body and bullets never echo the headline or each other."""
    clean_hl = headline.strip()
    norm_hl = clean_hl.lower()
    
    # If body is just the headline repeated or empty, expand with high-signal context
    if not body or body.lower() == norm_hl:
        body = f"Key architectural tradeoffs and implementation principles behind {clean_hl}."
        
    unique_points = []
    seen = {norm_hl}
    for p in points:
        p_clean = p.strip()
        if p_clean.lower() not in seen and len(p_clean) > 10:
            seen.add(p_clean.lower())
            unique_points.append(p_clean)
            
    return clean_hl, body, unique_points
```
