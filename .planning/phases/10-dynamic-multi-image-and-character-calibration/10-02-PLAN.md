## 1. Context & Objectives

PDF carousels are fragile on social media platforms, requiring heavy OS file dialogues and complex sub-menus. In contrast, all 4 target platforms (X, Bluesky, LinkedIn, Threads) natively support high-resolution PNG image sets.

**Goals:**
1. Replace slow CDP `Page.printToPDF` with lightning-fast CDP `Page.captureScreenshot` (retina 2x resolution, 2160x2160 output at 1080x1080 CSS viewport).
2. Render exactly $N \in \{1, 2, 3\}$ image cards per post based on `determine_card_count()`.
3. Apply `/gpt-taste` design engineering:
   - Deep `#080A0F` canvas with singular `#00E599` emerald accent.
   - Google Fonts `Geist` and `Geist Mono`.
   - Max 2-line wide headings (zero 6-line wrapping walls of text).
   - Crisp author identity watermark: `@Lordporus • OmniPost`.
   - Dynamic slide pagination indicator: `01 / 02`, `02 / 02`.

## 2. Technical Specification

### 2.1 Multi-Card PNG Export in `render/cards.py`
Create `render/cards.py`:
```python
async def render_cards_cdp(slides: list[dict[str, Any]], output_dir: Path, base_name: str, port: int = 9444) -> list[Path]:
    """Renders 1, 2, or 3 standalone 1080x1080 retina PNG images via CDP captureScreenshot."""
    output_dir.mkdir(parents=True, exist_ok=True)
    generated_paths: list[Path] = []
    
    # 1. Render HTML for each slide individually into template
    # 2. Attach CDP session to local Chrome/Edge
    # 3. For each slide, set viewport to 1080x1080, deviceScaleFactor=2.0
    # 4. Capture screenshot as PNG and save to scratch/cards/{base_name}_card_{idx}.png
    return generated_paths
```

### 2.2 Template Architecture (`render/card_template.html`)
- Dedicated standalone card template.
- 1080x1080 absolute dimensions.
- Zero margin/padding overflows.
- Anti-void verified: every card is filled with structured architectural insight, key takeaways, and system design metrics.
