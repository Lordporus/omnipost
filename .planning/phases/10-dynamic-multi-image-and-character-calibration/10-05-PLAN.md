## 1. Context & Objectives

Integrate all previous plans into a single, cohesive workflow:
1. `scripts/pipeline.py` fetches live daily swipe intelligence without text echoing.
2. `scripts/generate.py` generates dynamic topics and calculates 1, 2, or 3 cards based on content depth.
3. `render/cards.py` compiles 1–3 retina PNG cards into `scratch/cards/`.
4. `scripts/repurpose.py` crafts copy tailored to the exact character ceiling of each platform.
5. `scripts/publish_now.py --fresh` publishes the post and attaches the 1–3 PNG images across all 4 platforms.

---

## 2. Technical Specification

### 2.1 Unified CLI Pipeline Invocation
```powershell
# 1. Isolated dry-run test with fresh research and dynamic image generation
python scripts/publish_now.py --fresh --dry-run

# 2. Live drop across all 4 platforms with 1-3 visual cards attached
python scripts/publish_now.py --fresh
```

### 2.2 Live Publishing Verification Protocol
- **X:** Verified via tweet URL and profile presence with 1–3 images.
- **Bluesky:** Verified via ATProto post URI with 1–3 images.
- **LinkedIn:** Verified via activity feed URL with 1–3 images attached.
- **Threads:** Verified via user profile feed with 1–3 images attached.

---

## 3. Verification Criteria
1. Executing `python scripts/publish_now.py --fresh --dry-run` displays:
   - Green session OK for X, Bluesky, LinkedIn, Threads.
   - Character counts strictly within bounds (X: $\le 280$, Bluesky: $\le 300$, Threads: $\le 500$, LinkedIn: $> 1000$ and $\le 3000$).
   - 1 to 3 PNG images listed as media targets.
2. Full live drop produces 4 green checkmarks with verified URLs on all platforms.
