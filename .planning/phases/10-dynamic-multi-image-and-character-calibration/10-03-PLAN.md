## 1. Context & Objectives

The recent live run revealed two adapter-level issues:
1. **LinkedIn Document Failure:** The document option is hidden inside `button[aria-label="Expand content types"]` (`+`), while the **Media** button (`button[aria-label="Media"]`) is always directly visible on the main toolbar.
2. **Threads Composer Focus Failure:** Threads desktop web requires triggering the top-level composer or left-nav `Create` action (`svg[aria-label="Create"]` / `div[aria-label*="Empty text field"]`) and settling before the Lexical rich-text container mounts.

**Goals:**
1. Upgrade `adapters/linkedin.py` to upload 1–3 PNG images natively via the direct `Media` file input (`input[type="file"][accept*="image"]`), completing in < 1.5s with zero modal detours.
2. Upgrade `adapters/threads.py` to trigger the composer dialog reliably and attach 1–3 images via its file input.
3. Ensure `adapters/x.py` and `adapters/bluesky.py` cleanly attach the 1–3 images to their respective payloads.

### 2.1 Fast-Path Media Upload in `adapters/linkedin.py`
```python
async def _attach_images(self, page: Session, image_paths: list[Path]) -> bool:
    """Attaches 1-3 PNG images directly to LinkedIn post composer."""
    if not image_paths or not any(p.exists() for p in image_paths):
        return False
        
    resolved_files = [str(p.resolve()) for p in image_paths if p.exists()]
    
    # 1. Trigger Media button if file input is not yet mounted
    media_btn_js = """
    (() => {
        const btn = document.querySelector('button[aria-label*="Media" i]')
            || document.querySelector('button.share-promoted-detour-button[aria-label*="photo" i]');
        if (btn) { btn.click(); return true; }
        return false;
    })()
    """
    await page.eval(media_btn_js)
    await asyncio.sleep(1.0)
    
    # 2. Inject files via CDP DOM.setFileInputFiles
    # 3. Click 'Next' in the media preview dialog to return to post composer
    return True
```
