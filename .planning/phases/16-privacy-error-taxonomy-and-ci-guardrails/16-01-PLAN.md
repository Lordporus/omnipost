Output: a redacting artifact writer, a typed error hierarchy enforced in adapters, fixture-DOM selector tests, 9:16 golden tests, and a manual live-smoke workflow.
</objective>

<task type="auto">
  <name>Task 2: Enforce the typed error hierarchy in adapters</name>
  <files>scripts/errors.py, adapters/base.py, adapters/linkedin.py, adapters/threads.py, adapters/x.py, adapters/bluesky.py</files>
  <read_first>scripts/errors.py, adapters/base.py, adapters/linkedin.py, adapters/threads.py, adapters/x.py, adapters/bluesky.py</read_first>
  <action>
Use the shared hierarchy in `scripts/errors.py`; do not redefine it in `adapters/base.py`. This task is additive: keep the existing `ContentError` and `StateError` bases and their subclasses from Phases 11–12. Only the adapter-facing errors gain `platform`, `stage`, and `context`, and they are included in `__str__`:
```python
class AdapterError(Exception): ...
class SelectorError(AdapterError): ...
class ComposerOpenError(AdapterError): ...
class VerificationError(AdapterError): ...
class RateLimitError(AdapterError): ...
```
Do not reparent `StateCorruptionError`/`StateLockTimeout` to `AdapterError`; they remain `StateError` subclasses so a top-level `except AdapterError` does not swallow lock timeouts. Do not redefine `RenderError` (Phase 15) or `CopyValidationError`/`MediaContractError` (Phase 14); they keep their existing bases. Re-export only the adapter-facing classes from `adapters/base.py` for compatibility.

Sweep `adapters/linkedin.py`, `adapters/threads.py`, `adapters/x.py`, and `adapters/bluesky.py`:
- Replace `except Exception: pass` and broad `except Exception` blocks with specific catches. At the top-level `publish`, catch `AdapterError` and return a failed `PublishResult`; let programming errors propagate or convert them to `AdapterError` with a stack trace in the log.
- Remove redundant tuples such as `(CDPError, OSError, asyncio.TimeoutError, Exception)`.
- Add contextual `SelectorError` raises for every selector miss, including the selector string and candidate count.
- Ensure `verify` failures raise `VerificationError` or return `False` according to the contract; do not swallow.
  </action>
  <verify>python -m py_compile scripts/errors.py adapters/base.py adapters/linkedin.py adapters/threads.py adapters/x.py adapters/bluesky.py; if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }; rg -n -U "except Exception:\s*\n\s*pass" adapters/; if ($LASTEXITCODE -eq 1) { exit 0 } else { exit 1 }</verify>
  <acceptance_criteria>
    - The shared typed error classes exist and carry context; no module redefines them.
    - No adapter contains `except Exception: pass`.
    - Selector misses raise `SelectorError` with the selector.
    - Unexpected errors are not silently converted to success.
    - Bluesky is included in the sweep.
  </acceptance_criteria>
  <done>Adapter failures are typed, contextual, and observable.</done>
</task>
