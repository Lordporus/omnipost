## 1. Context & Objectives

In live operations, social platform post verification and operator notifications have two major failure modes:
1. Navigating away from `https://www.linkedin.com/feed/` to `/recent-activity/all/` destroys the ephemeral submission toast containing the direct post URN link, and CDN caching on the activity feed causes false-negative verification failures.
2. Sudden network slowdowns or packet drops can hang automation or cause ambiguous failures where a post is live but the operator receives no alert.

**Goal:**
1. Update `adapters/linkedin.py` to extract `urn:li:activity` directly from the in-page confirmation toast immediately after post submission, obtaining the permalink with zero page navigation.
2. Implement pre-flight reachability checks (`https://www.google.com/generate_204`) with a 3-second timeout to defer tasks gracefully when offline.
3. Handle network timeouts cleanly in `scripts/publish_now.py`: log `network_timeout` to `state.json`, dispatch an amber warning to Telegram, and move to the next platform without blocking.
4. Format rich Telegram notification cards with direct clickable post URLs and platform status badges.

## 2. Technical Specification

### 2.1 LinkedIn Toast Extraction (`adapters/linkedin.py`)
- After clicking the Post button and waiting 2–4 seconds on `https://www.linkedin.com/feed/`:
  - Evaluate DOM query:
    ```javascript
    (() => {
      const toastLink = document.querySelector('a[href*="/feed/update/urn:li:activity:"]');
      if (toastLink) return toastLink.href;
      const toastSpan = [...document.querySelectorAll('span')].find(s => (s.innerText || '').toLowerCase().includes('post successful'));
      if (toastSpan) return 'success_toast_detected';
      return null;
    })()
    ```
  - If a URN link is returned, extract the ID and set `res.url = toast_url`, `res.verified = True`.
  - Only fall back to open-feed DOM queries if the toast is missed.

### 2.2 Pre-Flight Connectivity & Lean Network Resilience
- In `scripts/publish_now.py`:
  - Implement `check_connectivity(timeout: float = 3.0) -> bool`:
    - Attempt `urllib.request.urlopen("https://www.google.com/generate_204", timeout=timeout)`.
    - If unreachable, emit `[WARN] Internet connection unreachable. Deferring publishing.` and exit cleanly.
  - Wrap platform execution in `ThreadPoolExecutor(timeout=args.timeout)`:
    - If `TimeoutError` or `urllib.error.URLError` occurs:
      - Record `status: "network_timeout"`, `verified: false`.
      - Send amber Telegram alert:  
        `"⚠️ [Platform] Post attempt timed out due to unstable network. Check your feed before retrying."`
      - Continue to next platform.
