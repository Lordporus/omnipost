## 1. Context & Objectives

OmniPost v2.5 must be consumer-ready for users downloading a `.zip` file on Windows or macOS. Currently, users face manual terminal friction (creating virtual environments, installing pip dependencies manually), vendor lock-in to hardcoded AI models, and confusing Telegram `400: chat not found` errors if they haven't sent `/start` to their bot first.

**Goal:**
1. Provide single-click root installers (`setup.bat` for Windows, `setup.sh` for macOS/Linux) that automatically initialize `.venv`, install `requirements.txt`, and launch the onboarding wizard.
2. Upgrade `scripts/wizard.py` to allow selecting among 4 AI providers (Gemini, OpenAI, Anthropic, OpenRouter), presenting recommended default models while allowing custom Model ID input.
3. Implement a zero-token pre-flight model validation probe in `wizard.py` that checks model existence via metadata APIs before saving to `config.json`.
4. Implement an immediate interactive Telegram bot test ping in `wizard.py` to verify credentials and guide the user if `/start` hasn't been sent.

## 2. Technical Specification

### 2.1 1-Click Bootstrap Installers
- **`setup.bat` (Windows):**
  - Check if Python 3.10+ is available on PATH. If missing, print a download link and exit cleanly.
  - Check if `.venv` exists. If not, run `python -m venv .venv`.
  - Activate virtual environment: `call .venv\Scripts\activate.bat`.
  - Run `pip install --upgrade pip` and `pip install -r requirements.txt`.
  - Launch `python scripts/wizard.py`.
- **`setup.sh` (macOS/Linux):**
  - Verify Python 3.10+ exists (`python3 --version`).
  - Create and activate `.venv`.
  - Install dependencies and execute `python3 scripts/wizard.py`.

### 2.2 Provider & Model Selection Wizard Flow
- In `scripts/wizard.py`, replace single-provider assumptions with an interactive prompt:
  ```text
  Select AI Provider:
    [1] Google Gemini (Recommended - Fast & Low Cost)
    [2] OpenAI (GPT-4o / GPT-4o-mini)
    [3] Anthropic Claude (Claude 3.5 Sonnet)
    [4] OpenRouter (Multi-model router)
  ```
- After entering the API key, prompt for Model ID with default shown:
  ```text
  Enter Model ID [Default: gemini-2.5-flash]: 
  ```
- **Zero-Token Pre-Flight Model Probe (`verify_model`):**
  - **Gemini:** `GET https://generativelanguage.googleapis.com/v1beta/models/{model_id}?key={key}`
  - **OpenAI:** `GET https://api.openai.com/v1/models/{model_id}` with `Bearer {key}`
  - **OpenRouter:** `GET https://openrouter.ai/api/v1/models`
  - **Anthropic:** Minimal message request (`max_tokens=1`)
  - If valid (HTTP 200), save `provider` and `model` to `config.json`.
  - If invalid (HTTP 404/401/403), display exact error and prompt to re-enter.

### 2.3 Interactive Telegram Bot Ping Test
- When user enters `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID`:
  - Dispatch a live test message: `"OmniPost connection confirmed! Your alerts will appear here."`
  - If successful, print `[OK] Telegram Bot verified successfully.`
  - If `400: chat not found`, print:
    `[WARNING] Telegram returned 'chat not found'. Please open your bot in the Telegram app and click '/start', then press Enter to retry.`
