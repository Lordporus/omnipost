  <action>
Add `CopyValidationError` and `MediaContractError` to `scripts/errors.py` and import them in `platform_limits.py` and `adapters/linkedin.py`. Do not define duplicate classes in those modules.

Create `scripts/platform_limits.py` with:
```python
LIMITS = {
    "x": {"min": 220, "max": 275, "hard_max": 280},
    "bluesky": {"min": 240, "max": 295, "hard_max": 300},
    "threads": {"min": 350, "max": 480, "hard_max": 500},
    "linkedin": {"min": 1500, "max": 2500, "hard_max": 3000},
}
```
Functions:
- `count_x_weighted(text: str) -> int` — ASCII/URLs count 1; CJK ranges and emoji count 2; document the ranges used.
- `count_graphemes(text: str) -> int` — use `unicodedata` combining/ZWJ handling; document that it is an approximation.
- `count_chars(text: str) -> int` — code points.
- `count_for(platform: str, text: str) -> int` — dispatch to the right counter.
- `truncate_words(text: str, limit: int, platform: str, ellipsis: str = "...") -> str` — cut at the last whitespace before the weighted budget. Convert the character/word budget to the platform's weighted count before cutting; do not treat `limit` as a raw character offset for X. Reserve room for the ellipsis, never split a word, and preserve URLs where possible.
- `validate(platform: str, text: str) -> None` — raise `CopyValidationError` if below min or above hard_max; include the platform, measured count, and limits.
- `fit(platform: str, text: str) -> str` — truncate to `max` on a word boundary; if the result is below `min`, raise `CopyValidationError` instead of padding.

Do not add third-party dependencies.
  </action>
  <verify>python -m py_compile scripts/errors.py scripts/platform_limits.py; python -c "from scripts.platform_limits import count_for, truncate_words; assert count_for('x','hello') == 5; assert truncate_words('one two three four', 12, 'x') == 'one two...'; print('ok')"</verify>
  <acceptance_criteria>

    - `truncate_words` never returns a partial word.
    - Emoji/CJK counts differ from plain code points for X.
    - `fit` raises rather than padding an undersized post.
  </acceptance_criteria>
  <done>A single limit engine is the source of truth for all platforms.</done>
