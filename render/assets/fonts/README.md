# Vendored fonts

These `.woff2` files are embedded into storybook cards at render time as base64
data URIs, so rendering never touches the network.

| File | Family | Weight |
| --- | --- | --- |
| `Geist-Regular.woff2` | Geist | 400 |
| `Geist-SemiBold.woff2` | Geist | 600 |
| `GeistMono-Regular.woff2` | Geist Mono | 400 |

Source: `geist@1.3.1` (https://github.com/vercel/geist-font), fetched once at
development time and committed here.
